> 起因：Tutu 问「我们是不是一开始方向就错了，直接用 DSH 连 QQBot 会不会更好」
> 结论：**方向没错，但确实缺一块 —— 已经补上了。**

## 一、查证过程（四轮否定，最后落地）

### 假设 1：直接换 DSH 跑群聊

查 [tencent-connect/dsh-qqbot](https://github.com/tencent-connect/dsh-qqbot)（腾讯官方）：

| 能力 | 有吗 |
| --- | --- |
| 多群独立会话 | ✅ `sessionKey: qqbot:${appId}:${scope}:${peerId}` |
| 重启恢复 | ✅ SHA-256 派生 SessionId |
| 群聊 @ 才回 | ✅ `requireMention` |
| 图片理解 | ✅ |
| **主动做事**（刷视频/玩游戏） | ❌ **完全没有，纯被动** |
| **果壳游戏整套** | ❌ 不存在，要重写 |
| **发言门控** | ⚠️ 只有 "@ 才回" 两档 |

**否定**：会丢掉 40 轮打磨的群聊能力 + 果壳游戏。

### 假设 2：调 DSH 桌面版 API

实测：

```
端口 8326 / 56045 / 56046 / 56047 → 全部 401
dsh 命令 → 不在 PATH
app.asar → 182MB 打包归档，不是 CLI
dsh-api-gateway → 是 Host/Client 间 RPC，不对外
```

**否定**：要内部 token，且是私有接口，升级易碎。

### 假设 3：装独立 dsh CLI

官方文档说：`dsh --profile headless "任务"`

**可行**，但要单独装一套，而且模型还得再配。

### 假设 4（成立）：直接用 WorkBuddy 桥

Tutu 说：「只要是花 workbuddy 积分里的 dsv4.1f 就行」

**关键发现**：`127.0.0.1:8899` 是 **OpenAI 兼容接口**，模型列表里有 `deepseek-v4.1-flash`。

实测（`tools\_p204_bridge_poc.py`，4/4）：

| 能力 | 结果 |
| --- | --- |
| 基础对话 | ✅ 4.1 秒 |
| **工具调用** | ✅ `finish_reason: tool_calls` |
| 长上下文理解 | ✅ 20 条消息正确总结 |

**DSH 的价值不是那个框架，是它背后的强模型 + 工具调用能力。这两样桥已经提供了。**

## 二、落地了什么

### 2.1 `src/maisaka/utils/capability_bridge.py`

能力扩展桥。核心 API：

```python
await delegate_task(instruction, context=材料, model="deepseek-v4.1-flash")
await summarize(long_text)      # 总结
await analyze(question, material)  # 带材料问答
```

**设计要点**：

| 点 | 为什么 |
| --- | --- |
| 失败返回 `ok=False`，**不抛异常** | 外包挂了不能把大肥鱼拖垮 |
| `asyncio.to_thread` 包 urllib | 同步 IO 不能阻塞事件循环 |
| context 超 24000 字自动截断 | 防止爆 token |
| 走 `127.0.0.1:8899` | 和 MaiBot 自己同一个 WorkBuddy 积分池 |

### 2.2 `src/maisaka/builtin_tool/think_hard.py`

给大肥鱼用的工具。注册参数：

```python
BuiltinToolEntry(
    "think_hard", ..., stage="action",
    visibility="deferred",   # 不占默认 prompt，模型需要时 tool_search 找出来
    chat_scope="group",
)
```

**工具描述里明确写了「什么时候别用」**：
- 普通寒暄、接梗 —— 自己就能答，别绕一圈
- 需要记住的事 —— 这工具**没有记忆**
- 群聊里已说清楚的事 —— 别为了显得聪明去调用

## 四、这意味着什么

### 现在大肥鱼能做什么

```
群友发了一大段文章
  → 大肥鱼自己看不懂
  → 调 think_hard（走 WorkBuddy 积分）
  → 拿回总结，用自己的口吻转述
```

**成本**：只在调用时花，平时不花。

### 不能做什么（诚实边界）

| 不能 | 为什么 |
| --- | --- |
| 执行本地文件操作 | 那要另接工具，桥只给推理 |
| 替代长期记忆 | 记忆还是 MaiBot 的 A_memorix |
| 替代群聊门控 | 那是第 203 轮的激活门控 |
| 保持对话状态 | 每次调用都是独立的 |

**它是"外包一次推理"，不是"另一个大肥鱼"。**
