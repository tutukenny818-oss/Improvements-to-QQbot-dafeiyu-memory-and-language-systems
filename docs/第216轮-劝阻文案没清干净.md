## 一、真正的来源（三处，都不在上一轮范围内）

### 1.1 `config\bot_config.toml` → `chat.reply_style.group_chat_prompt`

**每轮都进 prompt**，这是最大的一处：

```
★ 但也**别连着刷**：刚发过就先别发，同一个话题不重复发，正经问题别用图糊弄。
群友发的表情包你不用逐条回应，看懂意思就行。
控制回复的频率，不要每个人的消息都回复，优先回复你感兴趣的或者主动提及你的。
```

改后：

```
★ **想发就发，不用攒着**：同一句图别一字不差连贴两次就行，换张图、或者接着聊同一件事都是正常的。
群友发的表情包你看懂意思就行，想接就接一张，不想接也不用勉强。
★ **想回就回**：群友在聊你懂且想插嘴的话题就接一句，没什么想说的就看着 ——
  不用每句都回，也不用刻意少回。
```

### 1.2 `plugins\human-life\plugin.py` → `human_touch` 工具描述

在 `tool_definitions` 里，每轮都在：

```
想用就用，别每轮都调；同一个人同一天别重复做同一件事。
```

**这句话自相矛盾**：「想用就用」和「别每轮都调」是相反的指令，模型只能选保守的那个。

改后：

```
想用就用，不用攒着；只要同一轮里别对着同一个人连做两下就行。
```

只防「同一秒连点同一个人」这个机械感，不再限制频次。

### 1.4 顺手：`send_emoji` 的「什么时候别用」

```
## ⚠️ 什么时候别用
· 连着几条都发表情包（会像刷屏），至少隔一条文字；
· 刚刚才发过一张，同一个话题别再来第二张。
```

```
## ⚠️ 什么情况不太合适
· 对方在问正经问题、需要你给准确信息时（图会把答案淹掉）；
· **同一张图**别一字不差连贴两次 —— 换一张、或者接着聊都是正常的。

保留「正经问题别用图」—— 那是**判断**，不是限制。

## 四、连带发现的一处自相矛盾

`human_touch` 原文：

```
想用就用，别每轮都调；同一个人同一天别重复做同一件事。
```

「想用就用」+「别每轮都调」= 模型只能选保守的。这类**内部矛盾**比单纯的限制更糟：
它让模型无法判断哪个优先，最后总是选「少做」。

排查时值得专门找这种句型：**「想 X 就 X」后面跟「但别 Y」**。

## 六、以后怎么防

**不要用「我在哪个文件里 grep 到了什么」当作结论。**

核查劝阻文案的正确姿势：

1. 找到那轮的真实 prompt：`logs\maisaka_prompt\planner\<chat>\<ts>.json`
2. 在里面搜那个词
3. 用 `request_items` 的路径定位它来自哪一段（system prompt / attention block / tool_definitions / 历史消息）
4. **改完再跑一遍第 1 步**

```
