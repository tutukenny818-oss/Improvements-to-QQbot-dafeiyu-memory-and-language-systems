### 4.1 `tools\_p194_run_regression.py`（回归运行器）

一句话：**把 §五 那 22 条命令变成一条，并且能认出「exit 1 其实是 WARN」这种坑。**

```powershell
$py = "D:\MaiBot\.venv\Scripts\python.exe"

# 不停 bot 的那批（含三个探针）
& $py -X utf8 D:\QQBot\tools\_p194_run_regression.py --probes

# 停 bot 之后跑写路径那批
& $py -X utf8 D:\QQBot\tools\_p194_run_regression.py --locked

# 两批一起（锁被占时写路径批次自动 SKIP，不会撞锁）
& $py -X utf8 D:\QQBot\tools\_p194_run_regression.py --all --probes

# 出报表（md + json 各一份，方便两轮对比）
& $py -X utf8 D:\QQBot\tools\_p194_run_regression.py --all --probes `
    --report D:\QQBot\logs\regress.md --json-out D:\QQBot\logs\regress.json
```

它解决的四个具体问题：

1. **判据不能只看 exit code** —— 优先抓 `总计 X 通过 / Y 失败`、
   `N 项异常，M 项警告`、探针的 `注册指令数: N` / `-> OK` 计数；
   抓不到才回落 exit code，并在实测列里标「无自查汇总行」，提醒这是弱判据。
2. **探针必须用果壳 venv** —— `_probe_*.py` 里 `from dotenv import load_dotenv`，
   用 `D:\MaiBot\.venv` 或系统 python 会直接 `ModuleNotFoundError`。
   AGENTS.md 里那句裸 `python` 只在「果壳 venv 已激活」的 shell 里成立。
3. **绝不自动停 bot** —— 需要锁的用例在锁被占用时标 SKIP 并打印持锁 pid，
   停 bot 这种有副作用的动作留给人。
4. **超时能杀干净** —— 评测类脚本走 `--slow-timeout 900`，到点标 TIMEOUT 不挂死。

## 五、这轮踩到的运维坑（新加第 4 条）

**`开机重启大肥鱼.ps1` 会把 `dfy_panel.py`（5098）一起清掉。**

证据：重启前 5098 在监听（pid 1936/15552），重启脚本执行「清掉旧的大肥鱼进程」之后
5098 消失；手动补起后面板 `HTTP 200`。

所以「重启大肥鱼」的完整动作是 **两步**：

```powershell
# 1) 主流程
powershell -NoProfile -ExecutionPolicy Bypass -File D:\MaiBot\开机重启大肥鱼.ps1 -SkipWait

# 2) 补面板（脚本会连带杀掉，必须补）
Start-Process "D:\MaiBot\.venv\Scripts\python.exe" `
  -ArgumentList '-X','utf8','D:\QQBot\tools\dfy_panel.py' `
  -WorkingDirectory "D:\QQBot" -WindowStyle Hidden

# 3) 校验 7 个端口齐
Get-NetTCPConnection -State Listen |
  Where-Object { $_.LocalPort -in 3001,8898,8897,8001,5098,5099,8899 } |
  Select-Object -ExpandProperty LocalPort | Sort-Object -Unique
```

> 这一条和交接文档里「`停止大肥鱼.bat` 过滤太宽会杀 `dfy_panel`」是同一类坑的
> **另一半**：不只是「停止」脚本，**重启**脚本也会。以后看到「面板打不开」先补面板，
> 别去翻面板代码。
