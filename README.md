# 大肥鱼

> 一个住在 QQ 群里的 AI 角色。不是客服，是个会嘴硬的群友。
>
> 这个仓库不是框架，是**在 [MaiBot](https://github.com/Mai-with-u/MaiBot) 上做的一层拟人化改造** ——
> 人设、行为调校、运维脚本，以及 20 份真实故障复盘。

---

## 先说清楚这是什么

MaiBot 是一个成熟的 QQ 机器人框架：能接消息、能调模型、有插件系统、有 WebUI。

**但框架只负责「能说话」，不负责「像个人」。** 中间那层很薄、很容易被忽略，却决定了群友最后是觉得「这机器人挺有意思」，还是「这 bot 怎么老插嘴」。

大肥鱼就是这一层。具体做了三件事：

| | 做了什么 | 效果 |
| --- | --- | --- |
| **① 人设** | 一个具体的人：蓝发、围裙、鱼尾、傲娇、爱吐槽、护食 | 不是"AI 助手在群里"，是"群里那个叫大肥鱼的" |
| **② 该不该说** | 四分类门控（见下） | 大部分时候安静，被点名一定回 |
| **③ 说完之后** | 追问、催人、吐槽战况、不懂就问 | 不是一个"问答机"，是会接着聊的 |

**这个仓库的价值主要在 ③ 和那 20 份复盘** —— 因为 ①② 谁都能写，③ 得踩够坑才知道要做什么。

## 核心：它什么时候说话

这是整个项目最花时间的部分。**原则只有一句：沉默是安全的默认值。**

判据分四类（来自 [Speak or Stay Silent, arXiv:2603.11409](https://arxiv.org/html/2603.11409v1)）：

| 类别 | 判据 | 动作 |
| --- | --- | --- |
| **I1** 直接叫你 | `@它` / 叫名字+指令 / 名字+动词（「大肥鱼猜一个」） | **必须回** |
| **I2** 话题需要你 | 提到它+问号 / 玩法结算 / 第二人称+疑问 | 回 |
| **S1** 别人闲聊 | 没提它、没问号 | 拦（15% 概率放行，保留"偶尔插话"） |
| **S2** 提到你没跟你说 | 「大肥鱼今天怎么没说话」这类第三人称 | 拦 |

判完之后还有一层：**接续判断**。

- 它刚说完话，对方接一句「再来一局」→ 放行
- 它在这段对话里发过言，对方说「好吧看来你找不到」→ 放行
- 有人引用它的话回复 → 放行

**这些规则不是设计出来的，是被真实故障一条条逼出来的。** 每一条背后都有一份文档。

## 那 20 份文档才是重点

`docs/` 里不是教程，是**故障复盘**。每一份都是「它为什么不回我」的一个真实死法：

| 现象 | 根因 | 文档 |
| --- | --- | --- |
| 我发的消息它没回 | 它在正文里想好了，但没调 `reply` 工具 | [第207轮](docs/第207轮-没回应根因.md) |
| 「大肥鱼！」它不理 | 门控只读**最后一条**，点名被"补一句"盖掉了 | [第208轮](docs/第208轮-点名被吃掉.md) |
| 它把表情包当消息判 | 门控判的是缓存最新一条，不是 Planner 要回的那条 | [第209轮](docs/第209轮-门控拦错对象.md) |
| 回一句话要等 43 秒 | 「平均消息间隔」没有上限，冷群一次 4050 秒 | [第217轮](docs/第217轮-点名没反应与间隔无上限.md) |
| 它只会回一句 | 第 132 轮为保 @指令把断句整个关了，多句被压成一条 | [第212轮](docs/第212轮-只会回一句与只在一个群.md) |
| 玩完游戏就哑了 | 工具回执没提「回完说两句」+ 战况被判 S1 拦 | [第213-214轮](docs/第213-214轮-玩完不说话与限制文案.md) |
| 贴了个表情就没下文 | 回执只说「贴上了」，模型以为回应完成了 | [第220轮](docs/第220轮-贴表情当成回应.md) |
| 问完人一直不回也不催 | 上下文里没有「催一句也算正常」的依据 | [第215轮](docs/第215轮-问完没人回该不该催.md) |
| 不懂的词硬接 | 没有主动提问链路，只能靠词频被动挖掘 | [第219轮](docs/第219轮-不懂就问与引用归属.md) |
| 面板每次重启都没了 | 重启脚本用 `*MaiBot*` 模糊匹配，把面板一起杀了 | [第211轮](docs/第211轮-面板被杀根因.md) |

**如果你也在做群聊 bot，这些坑大概一个都躲不掉。**

## 想自己搭一个

这个仓库**不能直接 clone 就跑** —— 它没有框架本体。正确的顺序：

```bash
# 1. 先装框架
git clone https://github.com/Mai-with-u/MaiBot.git
cd MaiBot
# 按官方文档装依赖、配协议端（SnowLuma / NapCat）

# 2. 再看这个仓库，把人设和那层行为改上去
#    persona/ 和 patches/ 里写了具体改哪、为什么改

# 3. 关键：照着 docs/ 里的复盘一条条验
#    每条文档末尾都有「还差的验证」和验证脚本
```

这个仓库记的就是那件事。
