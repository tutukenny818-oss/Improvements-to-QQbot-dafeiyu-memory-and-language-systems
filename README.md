# 大肥鱼

> 一个住在 QQ 群里的 AI 角色。不是客服，是个会嘴硬的群友。
>
> 这个仓库分享四件事：**它什么时候说话**、**它怎么记事**、**它怎么和别的 bot 相处**、**它怎么刷视频**。

---

## 先说清楚：这不是从零写的

| 层 | 谁写的 |
| --- | --- |
| 对话框架 | [MaiBot](https://github.com/Mai-with-u/MaiBot) |
| 记忆系统实现 | [A-Dawn/A_memorix](https://github.com/A-Dawn/A_memorix) |
| **行为调校 + 全部评测与复盘** | **这里** |

**框架只负责「能说话」，不负责「像个人」。** 中间那层很薄，却决定了群友最后是觉得「这机器人挺有意思」，还是「这 bot 怎么老插嘴」。

**核心原则一句话：大部分时候不该说话就不说，被点名才一定回。**

判据来源：[Speak or Stay Silent (arXiv:2603.11409)](https://arxiv.org/html/2603.11409v1) ——
「轮次感知不是涌现能力，必须显式训练」。8 个模型零样本全失败。

**核心贡献不是「做了个记忆系统」，是「建了三个尺子」：**

| 尺子 | 量什么 |
| --- | --- |
| 八维度盘点 | 记得全不全 |
| 检索召回率 | 找得准不准 |
| 噪音量化 | 有没有噪音 |

可复现的数字：**30/30 日常问答 · 15/15 严格问答 · 召回@10 100% · 无证据 claim 0**

### ③ 和别的 bot 怎么相处 —— [`03-多机器人/`](03-多机器人/)

| 文档 | 讲什么 |
| --- | --- |
| [01-两个bot怎么不互相接话](03-多机器人/01-两个bot怎么不互相接话.md) | 在 QQ 眼里别的 bot 是普通用户 → 会滚成循环 |

**核心难点**：报文里 `bot` 字段是 False，不特殊处理就会互相接话、
两边都在烧模型积分、群里看起来是刷屏。

解法是两层：**不听它说的话**（不进记忆/不进判断）+ **但指令白名单照常执行**（否则没法一起玩游戏）。

### ④ 刷视频与看视频 —— [`04-视频采集/`](04-视频采集/)

| 文档 | 讲什么 |
| --- | --- |
| [01-刷视频与看视频](04-视频采集/01-刷视频与看视频.md) | 一出一进两个插件 |

**刷视频**的难点不是技术，是**别刷成机器人播报**。
**看视频**的难点是**别没看就瞎猜** —— 抽帧 + ASR，材料没准备好就不说话。

## 如果只读三份

1. **[01-对话系统/06-贴表情当成回应](01-对话系统/06-贴表情当成回应.md)**
   —— 「它没反应」不等于「它没试」。它搜了、想回、试了两次、被拦了两次、
   换了个动作、然后以为完成了。**只看最后一轮会完全误判。**

2. **[01-对话系统/14-劝阻文案的教训](01-对话系统/14-劝阻文案的教训.md)**
   —— 教你怎么查「模型真正看到了什么」。
   在源文件里 grep 到「已清干净」不等于清干净了 ——
   要去 `logs/maisaka_prompt/planner/` 的真实快照里搜。

3. **[02-记忆系统/05-编造数字与多值](02-记忆系统/05-编造数字与多值.md)**
   —— LLM 会凭空生成数字。核对方法很简单：
   **把值拿到 source 原文里搜一遍**。
